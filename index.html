The need

Explore a course inpatient dataset with 322,574 encounters and 41 prepared fields while keeping clinical and analytical definitions consistent.

Approach and contribution

I contributed to this graduate team project through an AI-assisted development workflow and participated in testing the visualization version. The project combines prepared data, pivot summaries, a data dictionary, clinical terminology references, and a local Flask application connected to Claude’s API.

A useful correction

Observed average length of stay and external arithmetic or geometric benchmarks answer different questions. The project documents that distinction in its reference files and agent instructions. It also records limits on questions the dataset cannot support, including readmission rates without suitable patient linkage.

Deliverables

The archive contains application code, interaction and version logs, presentations, and a ChatGPT adaptation package with an evaluation suite. Assistant-run checks and user testing are identified separately in project records.

What I learned

The quality of an analytical answer depends on definitions, source context, and verification as much as the language model.

02 / ACADEMIC TEAM PROJECT

Putting housing data
on common ground.

A county-level warehouse bringing property, crime, population, and economic data together for Arkansas market analysis.

SQL ServerPythonPower BI

“Can crime reduction be linked to increased home values?”

Research question · My individual housing submission
Read the project ↗

The team’s dimensional data model

View full size ↗

Original diagram · Team J Final Report.docx. Shared county and date dimensions connect the fact tables.

The need

Compare housing-market indicators across Arkansas counties using sources that did not begin at the same level of detail.

Team approach

The team integrated 2020–2023 data through a Census API/Python workflow and 15 CSV inputs. Four fact tables cover property, crime, population, and economics, connected through shared county and date dimensions.

My individual analysis

My individual submission investigated year-over-year crime changes alongside changes in average home sale prices. The team’s final report documents the data model, loading approach, and lessons from reconciling incompatible source grains.

What I learned

Choose the analytical grain before forcing sources together. Incomplete crime reporting limits comparisons, and a relationship between variables does not establish causation.
